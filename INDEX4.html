OLL

oll stands for orientation over last layer. in this step we solve the top layer of our cube. for example if we start from the white cross we will solve the yellow side completely in this step

MAKING THE CROSS

so basically since ur at a starting phase ur oll are separted into 2 phases also known better as "TWO LOOK OLL"

the first step is to make the cross

and the second is to solve it . kind of like what we do in beginner method with our starting color


so now here are the algorithms for the first step

DOT CASE

ALGORITHM: F ( U R U' R' ) F'

LINE CASE

ALGORITHM: F ( R U' R' ) F'

L CASE

ALGORITHM: F ( U R U' R' ) F'

SOLVING THE WHOLE SIDE

now that the first part of your oll is done lets move onto the second part of solving the side

here are the algorithms that you will need for this part

this section has 7 cases

CASE 1

ALGORITHM: R' U' R U' ( R' U2 R )

CASE 2

ALGORITHM: L U L' U ( L U2 L' )

CASE 3

ALGORITHM: R' U' R U' ( R' U R U' ) R' U2 R

CASE 4

ALGORITHM: R U2 R2' U' ( R2 U' R2' U2 ) R

CASE 5

ALGORITHM: R2 D ( R' U2 R ) D' ( R' U2 R' )

CASE 6

ALGORITHM: Rw U R' U' ( Rw' F R F')

CASE 7

ALGORITHM: x ( U R' U' L ) U R U' Rw'

so these are all the algorithms for beginner oll

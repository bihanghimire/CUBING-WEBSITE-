📖 Introduction to Speedcubing

Speedcubing is the practice of solving twisty puzzles (most commonly the 3x3 Rubik's Cube) in the shortest amount of time possible. What started as a casual puzzle in 1974 has grown into a global competitive sport with official WCA (World Cube Association) competitions held worldwide.

Key concepts:

· Methods — CFOP, Roux, ZZ, Petrus, and beginner's layer-by-layer
· Look-ahead — planning your next moves while solving the current step
· Fingertricks — efficient finger movements for faster turns
· TPS — Turns Per Second, a measure of raw turning speed
· Inspection — the 15-second preview before each solve

---

🧠 CFOP Method Algorithms

CFOP (Cross, F2L, OLL, PLL) is the most popular speedsolving method, used by the majority of world-class cubers. This project provides the complete algorithm set:

Stage Name Algorithms Purpose
C Cross — Solve the bottom cross
F2L First Two Layers 41 Solve the first two layers simultaneously
OLL Orientation of Last Layer 57 Orient all last-layer pieces
PLL Permutation of Last Layer 21 Permute all last-layer pieces

Total: 119 algorithms — the full CFOP set used by top solvers.
